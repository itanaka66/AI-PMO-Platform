PMOの知見を、実行可能なテンプレートとして書く。 A runtime that encodes PMO know-how as executable templates, run by combining LLM calls with the tools a team already uses.

会議の議事録から WBS を起こし、遅延を予測し、再計画案を人の承認待ちにして記録する—— 定例業務の一つひとつを YAML のテンプレートとして書き、Jira・Slack・Teams・PostgreSQL と つないで自律的に回す基盤です。 Drafts a WBS from meeting minutes, forecasts drift, and records a replan proposal pending human approval — one template per routine, wired to Jira, Slack, Teams, and PostgreSQL.

Architecture / 構想

経営者の承認を挟みながら回すループThe autonomous PMO cycle, gated by the executive/PM's approval

Template DSL

テンプレートは YAML、ロジックは持たせないTemplates are YAML — deliberately without a general-purpose logic engine

templates/examples/meeting_minutes.yaml
name: meeting_minutes
trigger: "event:teams:meeting_ended"

params:
  jira_project: PROJ

steps:
  - id: fetch_transcript
    adapter: teams
    action: get_transcript
    inputs:
      meeting_id: "{{ trigger.meeting_id }}"
    retry: { max_attempts: 3, backoff_seconds: 5 }

  - id: minutes
    llm: { profile: default, temperature: 0.1 }
    prompt: minutes_ja
    inputs:
      transcript: "{{ steps.fetch_transcript.output.text }}"
    output_format: json
    output_schema:
      required: [title, decisions, action_items]

  - id: register_jira
    adapter: jira
    action: create_issues
    when: "{{ steps.todos.output.items }}"
params.*実行時パラメータ / runtime parameters
trigger.*起動イベントのペイロード / trigger payload
run.*id / template / started_at / date
steps.<id>.output先行ステップの出力 / a prior step's output

for_each — 繰り返し

担当者ごとに1通ずつ送る、といった処理。1件の失敗で全体を止めない。要素ごとの絞り込みは where（when はループ前に一度だけ評価される）。

parallel — 並列実行

互いに依存しないステップを同時に実行。グループ内は互いの出力を参照できず、ロード時に検証される。全滅したときだけ工程自体が失敗になる。

agent — エージェント

決められた工程ではなく、AIが道具を選んで自分で呼ぶ。allow_writes: false が既定で、外の世界は変えさせない。

profiles — 複数プロバイダ同時

profile の代わりに配列で書くと、同じプロンプトを複数のLLMに同時投稿し比較できる。1つが落ちても他は止まらない。

Design decisions / 設計上の判断

なぜこの形にしたかA handful of the decisions this runtime is built on

数えれば決まる値を、モデルに数えさせない

完了率・残り日数はアダプタか組み込み変換で計算する。言語モデルに数えさせると間違えるし、間違えても正しそうに見える。

Countable facts are computed before the model sees them — a language model miscounts, and does so plausibly.

式評価を意図的に制限した

テンプレートは第三者が書いて配布される想定。値の参照と単純な二項比較しか許さず、汎用テンプレートエンジンを配布物の攻撃面にしない。

Templates are authored and distributed by third parties — a general-purpose engine would turn every one into an attack surface.

書き込みは読み取りより厳しく扱う

読み違いはやり直せるが、書いた誤りはやり直せない。エージェントに道具を渡しても、allow_writes: true が無ければ何も変わらない。

A mistaken read can be retried; a mistaken write cannot. Naming an adapter does not grant its write actions.

承認する側が居なければ、書き込みは通らない

require_approval: true は承認者が渡されて初めて機能する。渡さなければ、対話端末の無いスケジューラからの書き込みは常に断られる。

With no approver supplied, the write is always refused — exactly what happens on an unattended scheduled run.

逃した実行は流さない

正午に5日分まとめて送るのは通知の洪水であって報告ではない。同じ理由で、問題が無ければ何も送らない。

A flood of catch-up notifications is not a report. For the same reason, silence is the output when nothing is wrong.

公開可能性スコアはモデルに頼らない

知見の公開判定は必ず人間が行う。スコアは利用許諾レベルなど数えれば決まる範囲だけを見る、並び順のための下書きの値。

Whether something is safe to publish stays a human's call — the score only orders the review queue.
