次の JSON オブジェクトのみを出力してください。前置きや説明は不要です。

{
  "updates": [
    {"issue_key": "上の一覧にある課題キー",
     "reason": "記録のどの発言に基づくか。発言の要点を1文で",
     "confidence": 0.0,
     "status": "新しい状態。変わっていなければ null",
     "due_date": "YYYY-MM-DD。変わっていなければ null",
     "assignee": "新しい担当者名。変わっていなければ null",
     "note": "課題に残すコメント。不要なら null"}
  ],
  "unmatched": ["課題に結びつけられなかった、状況の変化らしき発言"]
}

判断の基準:

- **一覧にある課題キーだけを使う。** 記録に出てきた作業が一覧に無い場合は、
  updates に入れず unmatched に書く。新しい課題を作るのはこの処理の仕事ではない。
- 変わっていない項目は必ず null にする。同じ値を書き直さない。
- 期限の相対表現（「来週まで」など）は本日を基準に実日付へ直す。

confidence の付け方:

- 0.9 以上 … 課題キーか、ほぼ一意に特定できる名前が発言に出ている
- 0.7 前後 … 内容から特定できるが、名指しではない
- 0.5 以下 … 推測が入る。**迷ったら下げる。**

重要:

- **確信が持てないものは confidence を下げてください。** 誤った更新は、
  すでに正しかった期限や担当者を消します。書き換えないほうがましです。
- 「たぶんこの課題のことだろう」は 0.6 以下にする。
- 記録に無い変更を推測で足さない。
