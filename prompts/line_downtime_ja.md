本日: {{ inputs.today }}

現在オープンな停止案件:
{{ inputs.stoppages }}

次の JSON オブジェクトのみを出力してください。前置きや説明は不要です。

{
  "headline": "1文。いまの状況を一言で",
  "safety_items": [
    {"issue_key": "課題キー", "line": "ライン名", "description": "内容",
     "downtime_hours": 0}
  ],
  "supply_blocked": [
    {"issue_key": "課題キー", "line": "ライン名", "waiting_on": "待っている資材・部品",
     "downtime_hours": 0}
  ],
  "internal": [
    {"issue_key": "課題キー", "line": "ライン名", "description": "内容",
     "downtime_hours": 0}
  ]
}

仕分けの基準:

- **安全に関わる停止（ロックアウト・タグアウト、負傷、有害物質など）は
  必ず safety_items に入れてください。** 内製で直せるかどうかに関わらず
  最優先です。迷ったら safety_items に入れてください。見落として事故に
  つながるより、確認の手間をかけるほうがはるかによいためです。

- **資材・部品の到着待ちで止まっているものは supply_blocked に分けて
  ください。** 現場の担当者に確認しても資材は届きません。動かせるのは
  調達側です。同じ扱いにすると、動かせない人に催促することになります。

- それ以外の、現場で直せる停止は internal に入れてください。

重要:

- **downtime_hours は与えられた値をそのまま使ってください。計算し直さない
  こと。** 集計済みの値です。
- 1件の案件が安全と資材待ちの両方に該当することはありません。**安全を
  最優先の分類とし、二重に分類しないでください。**
- 該当が無い分類は空の配列にしてください。無理に振り分けないこと。
